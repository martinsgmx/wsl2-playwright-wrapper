# Configuration

## `opencode.jsonc` (project)

At repo root, `opencode.jsonc` points to the wrapper:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "playwright": {
      "type": "local",
      "command": ["bash", "scripts/mcp-wrapper.sh"],
      "enabled": true,
      "timeout": 10000
    }
  }
}
```

`opencode` loads `https://opencode.ai/config.json` schema, merges global + project (project wins). See https://opencode.ai/docs/mcp-servers and https://opencode.ai/docs/config/#precedence-order.

To disable temporarily without editing: set `"enabled": false` or run `opencode` with `OPENCODE_CONFIG` override.

## `scripts/mcp-wrapper.sh` flags

Wrapper auto-detects WSL host (`wsl-host-ip.sh`: `mirrored → localhost`, `NAT → gateway`) and builds:

```
npx @playwright/mcp@latest \
  --cdp-endpoint http://<host>:<port> \
  --isolated \
  --caps devtools \
  --secrets .secrets.env \
  --init-page scripts/init-auth.ts \
  --storage-state config/storage-state.json
```

- `--isolated` — fresh `BrowserContext` per session (required).
- `--cdp-endpoint` — from `CDP_PORT`/`CDP_HOST` env or auto-detected.
- `--secrets .secrets.env` — dotenv loaded into `process.env` for `init-auth.ts`. Omitted if file missing.
- `--init-page scripts/init-auth.ts` — Playwright page hook that auto-fills login.
- `--storage-state` — seed cookies/localStorage; omitted if `config/storage-state.json` missing/empty.
- `--caps devtools` — keep tool surface small (avoids context bloat). Add `vision,pdf` if you need screenshots/PDF.

Pass extra flags via wrapper: `bash scripts/mcp-wrapper.sh --headless` etc.

## `.secrets.env`

Loaded by Playwright MCP, not by opencode. Vars:

| Var | Required | Example | Meaning |
|---|---|---|---|
| `AUTH_URL` | yes for auto-login | `http://localhost:3000/login` | Full URL of login page; `init-auth.ts` acts only when `page.url()` contains its pathname or `/login`. |
| `AUTH_USERNAME` | yes | `test@example.com` | Filled into `AUTH_USER_SELECTOR`. |
| `AUTH_PASSWORD` | yes | `secret` | Filled into `AUTH_PASS_SELECTOR`. |
| `AUTH_SUCCESS_PATH` | yes | `**/dashboard**` | Glob for `page.waitForURL()` after submit. `**` matches any prefix/suffix. |
| `AUTH_USER_SELECTOR` | no | `input[name="username"]` | Default: `input[type="email"], input[name="username"], ...` |
| `AUTH_PASS_SELECTOR` | no | `input[name="password"]` | Default: `input[type="password"], input[name="password"]` |
| `AUTH_SUBMIT_SELECTOR` | no | `button[type="submit"]` | Default: `button[type="submit"], button:has-text("Log in"), ...` |
| `CDP_PORT` | no | `9222` | Overrides default 9222. |
| `CDP_HOST` | no | `localhost` | Overrides auto-detected host. |

File is `chmod 600` and **gitignored**. Keep `.secrets.env.example` committed with dummy values.

## `config/storage-state.json`

- Generated by `bash scripts/capture-storage-state.sh` (manual one-time login) or by `npx playwright` codegen.
- Shape: `{ "cookies": [...], "origins": [...] }`. Wrapper only uses it if it looks valid (`cookies` present).
- Gitignored. Commit only `storage-state.example.json` (empty).

## Redirect semantics

`init-auth.ts` does:

1. Check `page.url()` matches `AUTH_URL` pathname.
2. If `AUTH_USERNAME`/`PASSWORD` present and password field exists, fill + click submit.
3. `await page.waitForURL(AUTH_SUCCESS_PATH, { timeout: 15000 })` — succeeds when app redirects to e.g. `/dashboard`.

`AUTH_SUCCESS_PATH` is a Playwright glob: `**/dashboard**` matches `https://app.example.com/dashboard?x=1`. Use full URL if you need exact host.

## Per-project overrides

Each project that wants isolated browsing can copy `opencode.jsonc` + `scripts/mcp-wrapper.sh` pattern, or set `OPENCODE_CONFIG=/path/to/custom.jsonc`. The `wsl-chrome` folder on disk is the reference implementation of `playwright-wrapper-mcp`.
